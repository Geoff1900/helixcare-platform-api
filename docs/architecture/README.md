# HelixCare Architecture Overview

HelixCare is a fictional healthcare platform composed of
multiple services supporting clinical and administrative workflows.

This document provides a high-level view of the system architecture.

---

## Initial Service

Current implementation:

- HelixCare.Api
- ASP.NET Core Web API
- REST-based service interface

---

## Future Services (Planned)

- Master Patient Index (MPI)
- Referral Service
- Immunisation Service
- Messaging Service
- Clinical Records Service

---

## Platform Goals

- Cloud-native architecture
- Modular services
- Strong CI/CD automation
- High observability
- Secure-by-design
